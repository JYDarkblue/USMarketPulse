# Market Pulse | US Market Intelligence

**Market Pulse**는 글로벌 주요 경제·금융 미디어(CNBC, WSJ, Bloomberg, Guardian)의 신뢰할 수 있는 RSS 피드를 실시간으로 수집하여, 미국 시장의 핵심 뉴스를 한눈에 파악할 수 있도록 제공하는 모던 뉴스 대시보드 웹앱입니다.

## 🚀 바로 가기 : https://jydarkblue.github.io/USMarketPulse/

## ✨ 주요 기능
- **실시간 뉴스 브리핑**: 미국 시장, 거시경제 및 연준 정책, 빅테크 기업 실적, AI·반도체·에너지 산업 이슈 제공
- **한/영 다국어 지원**: 클릭 한 번으로 한국어 자동 번역 및 원문(English) 전환 가능
- **섹터별 확장/축소 기능**: 각 카드별 `+` / `-` 버튼을 통해 직관적인 화면 정리 및 카드 크기 자동 조절
- **자동 갱신 및 스피너 로딩**: 15분 주기 자동 업데이트 및 부드러운 로딩 스피너 애니메이션 제공
- **반응형 디자인**: PC와 모바일 환경 모두에 최적화된 인터페이스

---
## 🛠️ 기술 스택
- **Frontend**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Data Source**: CNBC, WSJ, Bloomberg, The Guardian RSS Feeds
- **Translation**: Google/MyMemory Translation API Integration
